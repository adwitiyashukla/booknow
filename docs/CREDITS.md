of a real hotel. Every image is served from `images.unsplash.com`, which is the only remote host
permitted by `next.config.ts`.

## A note on Unsplash+

Unsplash also sells **Unsplash+**, a paid tier whose images are served from
`plus.unsplash.com` and carry a different licence requiring an active subscription. Those are
deliberately excluded here: `next.config.ts` allows only `images.unsplash.com` as a remote image
host, so an Unsplash+ URL would fail to render rather than silently shipping content this project
is not licensed to use.
